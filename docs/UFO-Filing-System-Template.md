## 3. The twelve HAT labels

| Label | Meaning |
|---|---|
| **Established** | Accepted fact, checkable in standard sources |
| **Derived** | Follows by correct math or logic from what is given |
| **Tested** | Checked against data, with method and result on file |
| **Candidate** | Passed a first test; not yet confirmed |
| **Postulated** | Proposed; not yet tested |
| **Open** | A live question; not settled either way |
| **Faith** | Held in belief, not proved; stated as such |
| **Metaphor** | A picture that helps the mind; not a law |
| **Humor** | A joke, labeled so no one mistakes it for a claim |
| **Rule** | A saying or practice the owner lives by |
| **Superseded** | Replaced by a later, better entry (kept, not erased) |
| **Withdrawn** | Found wrong; kept on file with the reason |

## 4. The label on each kind of file

| File | Where the label goes |
|---|---|
| Text (.md, .txt, .docx) | Line 3, directly under the title: `Label: [App and version] Uniquea Field Observations UFO` |
| PDF | Top of page 1 |
| PNG and other pictures | A small footer line on the picture, and the same words in the file's description (metadata) |
| Code and data (.py, .csv, .json) | Not altered; listed in the index, so results still reproduce exactly |

The app's own name goes first, so every record shows where it was made: `Meta AI Uniquea Field Observations UFO`, `Grok Uniquea Field Observations UFO`, `Claude 5.2 Uniquea Field Observations UFO`.

## 5. How a record travels

1. **Made** in any app, by this template, with "UFO number: pending."
2. **Brought** to the archive (upload the file).
3. **Checked** against the Master: facts, dates, earlier entries.
4. **Filed** in the Master with its HAT labels; private parts held back.
5. **Numbered** in the [UFO Log](UFO-Log.md) if it is a public observation.
6. **Pushed** to GitHub only on the owner's word.
