# Planck Scale Reference Card

**Status:** Established (conventional physics)
**Checked:** October 7, 2026
**Constants:** CODATA values

## Planck units

```
ℓ_P = √( ħG / c³ )
m_P = √( ħc / G )
E_P = √( ħc⁵ / G )
```

| Quantity      | Symbol | Value                                   |
|---------------|--------|-----------------------------------------|
| Planck length | ℓ_P    | 1.616255 × 10⁻³⁵ m                      |
| Planck mass   | m_P    | 2.176434 × 10⁻⁸ kg                      |
| Planck energy | E_P    | 1.22 × 10¹⁹ GeV  (about 1.96 × 10⁹ J)   |

The Planck mass is about the mass of a flea egg.

## Loop quantum gravity: area spectrum

```
A = 8πγ ℓ_P² Σ √( j_l (j_l + 1) )
```

- The sum runs over the spin-network edges *l* that cut the surface.
- Each edge carries a half-integer spin *j_l*.
- γ is the Barbero-Immirzi parameter. Its value is not fixed by the theory.

## Area gap (smallest nonzero area)

Set a single edge to j = 1/2:

```
A_min = 8πγ ℓ_P² √( (1/2)(3/2) )
      = 4√3 πγ ℓ_P²
      ≈ 21.8 γ ℓ_P²
      ≈ 5.7 × 10⁻⁶⁹ γ m²
```

---

## Boundary note

The area gap is the spectrum of a geometric operator in a candidate theory. It is
not a measured grain of space. No observation has yet confirmed loop quantum
gravity over other approaches to quantum gravity.
